# Dedsafio4Addon

Dedsafio4Addon is a Minecraft Bedrock Edition plugin that enhances your gameplay with a comprehensive set of features inspired by the popular Dedsafío 4 series. This plugin offers a variety of skins for players, including a customizable otter skin, a system of professional-looking roulette wheels, and a range of commands to manage and interact with these features. The plugin is designed to be free, compatible with iPad, and suitable for multiplayer environments, providing a professional and immersive experience.

## Install

1. Download the latest release of Dedsafio4Addon from the GitHub repository.
2. Extract the downloaded ZIP file to your Minecraft Bedrock Edition world's `behavior_packs` and `resource_packs` folders.
3. Launch Minecraft Bedrock Edition and select the world where you extracted the plugin.
4. In the world settings, enable the `Challenge4BP` behavior pack and the `Challenge4RP` resource pack.

## Use

### Skins

1. To open the skins menu, use the command `/dedsafio skin`.
2. To view the available skins, use the command `/dedsafio skin lista`.
3. To equip a skin, use the command `/dedsafio skin equipar [nombre]`.
4. To remove a skin, use the command `/dedsafio skin quitar`.
5. To assign a skin to a player, use the command `/dedsafio skin asignar [jugador] [nombre]`.

### Roulette

1. To open the roulette panel, use the command `/dedsafio ruleta`.
2. To spin the roulette, use the command `/dedsafio ruleta girar`.
3. To select a random roulette, use the command `/dedsafio ruleta aleatoria`.
4. To view the result of the roulette, use the command `/dedsafio ruleta resultado`.
5. To configure the roulette options, use the command `/dedsafio ruleta configurar`.
